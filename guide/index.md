# Welcome to the Neuromatch Course Guide

The manual for the Neuromatch course kit, and a working example of a course built with it. Every page demonstrates what it explains, and most show **what you write** next to **what you get**.

New here? Read [What is the course kit?](start/what-is-the-kit.md), then [pick your path](start/which-path.md):

| You… | Go to |
|---|---|
| Write or convert tutorials | [For authors](author/index.md) |
| Create and run a course repository | [For maintainers](maintainer/index.md) |
| Teach with a course | [For instructors](instructor/index.md) |
| Look something up | [Reference](reference/index.md) |
| Want pages to copy | [Examples](examples/index.md) |
