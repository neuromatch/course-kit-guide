# Directive examples

For: author (example source)

Real pages that hold the examples the feature pages show. They are validated by `nma-kit check` like any page. Each shown region is wrapped in `% region-start: <name>` and `% region-end: <name>` comments.

- [Markdown basics](markdown-basics.md): admonitions and a table.
- [Code cells](code-cells.md): plain, `hide-input` and `remove-cell` cells (executable).
- [Video and slides](video-and-slides.md): `{nma-video}` and `{nma-slides}` (executable, so `:path:` works).
- [Exercise, solution and explanation](exercise.md): an exercise with `{nma-solution}` and `{nma-explanation}` (executable).
- [Feedback widget](feedback.md): `{nma-feedback}`.
- [Instructor note](instructor.md): `{nma-instructor}`.
